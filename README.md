## 📌 Project Overview

The **Airbnb Global Performance Dashboard** is a data analytics and business intelligence project developed to explore accommodation-market performance and identify meaningful patterns across cities, listings, hosts, and customer feedback.

Using Power BI and data visualization techniques, the project transforms raw data into an organized analytical dashboard that supports comparisons, trend analysis, and data-driven decision-making.

The project demonstrates an end-to-end analytics workflow, from understanding and preparing the dataset to designing visual reports and communicating business insights.

## 🎯 Project Objectives

- Analyze Airbnb performance across different cities.
- Compare revenue, occupancy, average rates, and vacant days.
- Explore listing and host distribution.
- Understand review and rating patterns.
- Identify differences in market performance across locations.
- Present complex data through clear, interactive visualizations.
- Develop practical skills in data analysis and business intelligence.

## 📊 Key Metrics Analyzed

- **Revenue:** Revenue patterns across cities.
- **Occupancy:** Occupancy performance and utilization.
- **Vacant Days:** Available-day patterns and vacancy-related performance.
- **Average Rate:** Comparison of average rates across locations.
- **Listings & Hosts:** Distribution of listings and host activity.
- **Ratings & Reviews:** Customer feedback and rating patterns.

*Note: The metrics and comparisons depend on the fields available in the source dataset.*

## 🔄 Project Workflow

1. **Data Understanding** — Reviewed the available dataset, columns, and analytical requirements.
2. **Data Preparation** — Checked data quality, handled errors and missing values where appropriate, and prepared the data for analysis.
3. **Data Modeling** — Organized the available fields and relationships as required by the report.
4. **Measure Development** — Used relevant calculations for metrics and comparisons.
5. **Dashboard Design** — Created visualizations for city-level performance, occupancy, revenue, rates, and ratings.
6. **Insight Exploration** — Compared metrics to identify patterns and differences between locations.
7. **Deployment** — Published a web-accessible version of the dashboard.

## 💡 Business Value

This dashboard can help users explore questions such as:

- Which cities show stronger performance across the available metrics?
- How do occupancy and vacant days vary by location?
- How does revenue differ between cities?
- What patterns appear in average rates and customer ratings?
- How is listing activity distributed across the selected locations?

These comparisons can support market research, performance monitoring, and further business analysis. The dashboard highlights patterns in the available data; it does not independently establish the causes behind them.
